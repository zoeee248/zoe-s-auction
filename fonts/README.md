# 字体说明

本包沿用用户确认版本的字体，不从第三方 CDN 加载。

- 阿里巴巴普惠体3：正文、按钮与通用界面文字，使用 Light / Regular / Medium WOFF 子集。来源与字符记录见同目录 JSON、TXT。
- Glow Sans（未来荧黑）：保留详情页标题的既有字形与 Regular / Medium WOFF 子集。版权许可见 GlowSans-OFL.txt。
- Caveat Brush：home 与英文标语，许可见 CaveatBrush-OFL.txt。
- Kanaka Hand：选用用户第一次字体包中的手写体，章节序号、标题、导语、引子和结尾相应文案使用。为既有字形覆盖保留局部繁体替换。

字体按已有文字制作子集；新增文字可能回退为系统字体。本包不包含原始 OTF 或历史字体构建环境。其他原有来源和版权记录仍随包保留。

- R14 新增 `KaushanScript-MeetZoe.woff`，仅用于 Meet Zoe。来源为 Google Fonts 的 `ofl/kaushanscript/KaushanScript-Regular.ttf`，保留相应 OFL 许可。
